# Контрольний список MathSpace

## Редактори
- [ ] Створення й повторне редагування уроку учня.
- [ ] Створення й повторне редагування шаблону бібліотеки.
- [ ] Обидва режими мають однакові поля й дії.
- [ ] Зміни шаблону не змінюють уже призначений урок.

## Завдання
- [ ] Один варіант.
- [ ] Кілька варіантів.
- [ ] Правда / неправда.
- [ ] Коротка відповідь.
- [ ] Розгорнута відповідь.
- [ ] Встановлення відповідності, включно з «Немає відповідності».
- [ ] Бали, правильні відповіді, пояснення зберігаються.
- [ ] Додавання, редагування, перестановка та видалення.

## Матеріали
- [ ] Презентація й конспект: додати, замінити, переглянути, видалити.
- [ ] Фото завдань зберігаються у правильному Storage bucket.
- [ ] Імпорт тексту й Gemini проходить попередній перегляд.

## Безпека та регресія
- [ ] Учень не може змінити правильні відповіді напряму.
- [ ] RLS не послаблено.
- [ ] Спроби й результати не зникли.
- [ ] Push-сповіщення працюють.
- [ ] Немає помилок у консолі.
- [ ] Перевірено мобільний інтерфейс.
